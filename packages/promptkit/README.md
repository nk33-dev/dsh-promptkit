# PromptKit

Turn rough ideas into prompts that work in DeepSeek Harness, with guided questions, project context, and reusable prompts.

先写个大概，边问边把需求补齐，好用的提示词留着下次接着用。

Supports DeepSeek Harness **0.2.1-rc.2**. Install the built package through Harness's plugin manager. The composer tools offer **Optimize prompt**, **Explore requirements** and **Library** in a side panel. Configure rules, models, presets and import/export under **Harness Settings → PromptKit**.

支持提示词优化、持续问答、可选项目资料、收藏和场景规则。需求小结确认后生成提示词，结果由用户写回和发送。
