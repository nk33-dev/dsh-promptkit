# 使用与安装

## 安装与升级

当前支持 DeepSeek Harness `0.2.1-rc.2`。在仓库根目录执行：

```sh
pnpm install
pnpm pack:plugin
```

打开 Harness「插件 → 添加插件 → 安装第三方插件」，输入 `dist/dsh-promptkit-0.1.2.tgz` 的绝对路径，安装后启用。开发时也可安装 `packages/promptkit` 目录。完整退出再打开可刷新 Host 模块。

可安装归档在 `dist/dsh-promptkit-0.1.2.tgz`。归档包含 Host、Client、类型、规则、语言包和 MIT 许可证，不包含密钥、个人数据或测试草稿。通过宿主插件管理器更换包后，重启加载新代码；宿主存储域中的数据继续保留。

## 提示词工具

输入草稿，点击输入框旁的工具图标，选择「优化提示词」或「梳理需求」。只启用一种能力时直接打开。右侧面板宽 600px，窄窗口全宽显示；结果可编辑、替换、追加、复制和收藏，不会自动发送。

优化模式直接补全需求，新增的范围和技术设定标为建议或假设。梳理需求每组最多三题，一次显示一题，切题保留答案；支持自行填写、还没想好和换个问法。轮数不限，需求小结由用户确认后生成提示词。可修改旧答案，后续内容会重新整理。

生成结果后可填写修改要求继续调整。关闭面板、打开收藏或切换会话不会丢失已完成的整理过程；退出客户端后清空，收藏长期保存。请求失败保留输入，关闭时取消请求。草稿改变会暂停整理，替换前检查会话、项目、版本、引用和附件。

## 模型与规则

在 Harness「设置 → PromptKit → 设置」中配置。默认使用 Harness 模型目录的默认模型，也可明确选择一个宿主模型。独立连接支持 Chat Completions、Responses、Anthropic Messages 和自动选择，Base URL 要包含服务的 API 前缀。

API Key 经宿主凭据服务保存；页面只能看到是否配置，无法读取已保存的值。修改凭据引用后，先保存设置再配置对应密钥。删除已保存密钥后，宿主仍可能使用同名环境变量等回退来源。

两组规则分别保存，留空使用内置规则。场景在面板内折叠，切换后重新开始生效。

## 项目上下文

默认关闭。开启后可分别选择四类内容：项目与分支、项目说明、两层目录、清单文件。选中的内容会发送给模型，预览里可以查看实际文本、截断和跳过原因。

总预算 14000 个 Unicode 字符；项目信息 512、说明 6000、清单合计 6000、目录 2000。单文件最多读取 32 KiB，目录最多列出 200 项、检查 400 项，跳过隐藏项、依赖、构建目录和链接。目录来自当前会话，无法确认时提示跳过。

## 收藏

收藏库无需模型连接。支持保存草稿、生成结果及手动新建。列表与正文分栏，窄窗口切换查看；追加为主要操作，编辑后点击保存才更新收藏。

书签入口独立打开收藏库；搜索返回摘要，选中后读取正文。导入导出位于 Harness「设置 → PromptKit → 收藏库」。

导出格式为 `{"version":1,"favorites":[...]}`。导入最多 8 MiB、5000 条，先查看新增与重复数量，再确认；重复 ID 跳过。整次校验失败时原库保持不变。

评分反馈已停用，旧数据保留。导出收藏前请检查其中是否包含敏感内容。

关闭单项功能保留设置和数据。停用插件会移除界面、取消进行中的请求并释放监听；已发出的请求是否停止计费由模型服务决定。
