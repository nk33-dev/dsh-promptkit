# PromptKit

**中文** · [English](README.en.md)

DeepSeek Harness 插件。在输入框旁把随手写的草稿整理成可直接发送的提示词；需求还不清楚时，先问几个关键问题再写。好用的提示词可以收藏，下次直接用。

![输入框旁的两个入口与模式菜单](docs/images/composer-menu.png)

## 安装

在 Harness 中打开 **插件 → 添加插件** 右侧箭头 → **安装第三方插件**，粘贴：

```text
github:nk33-dev/dsh-promptkit#path:/packages/promptkit
```

启用后重启 Harness。支持 Harness `0.2.1-rc.2`。仓库已带构建产物，本机不需要 Node 或 pnpm。

## 功能

- **增强提示词**：把草稿补全为完整的提示词。能定下的方案直接写明，只有你知道的信息留成【列表页 URL】这类空位，填好再发。
- **需求对齐**：按草稿的缺口提问。单选题带推荐和理由，也可以多选、自己填、暂不决定或交给 AI 决定；方向清楚就直接生成。
- **常用提示词**：即时搜索、按标签筛选、拖动排序，点一下追加到输入框，悬停可替换或编辑，删除可撤销。
- **写回由你确认**：结果可以继续修改，确认后追加或替换；替换可撤销，不会自动发送。

## 使用

草稿有内容时，点输入框旁的 ✨。两种模式都开启时先选模式，只开一种时直接开始。

- **需求对齐**：数字键选择，`←` / `→` 或圆点切换题目，推荐项排在最上面。看不懂可以点题目右侧换个问法；「直接生成」随时可用。
- **结果页**：在下方写修改要求，点「改进」或按回车继续调整；也可以重新生成、复制、存为常用、追加或替换。「改答案」回到问卷，什么都没改就继续时恢复原结果，不会再次调用模型。
- **常用提示词**：点 🔖 打开，「存当前输入」把草稿存为收藏。

卡片打开后输入框内容被改动时，流程会锁定并提示「按新内容重来」，不会覆盖你的修改。

## 设置

打开 **Harness 设置 → PromptKit**。

| 设置 | 说明 |
| --- | --- |
| 入口 | 三个入口各自开关，可设菜单首项 |
| 深度 | 微调只改措辞，篇幅与草稿相当；标准补清目标、核心内容和关键选型；详细按需写出具体方案。入口菜单可临时切换 |
| 受众画像 | 无技术经验、P4–P10（参照阿里职级能力）。只影响解释方式和决策深度，不决定系统规模 |
| 模型 | 使用 Harness 已配置的模型，或单独配置服务、模型和超时 |
| 规则 | 增强与提问规则可自定义，留空使用内置规则 |
| 项目上下文 | 默认关闭；开启后可分别选择项目名、说明、清单和目录 |
| 收藏导入导出 | `{"version":1,"favorites":[...]}`，最多 8 MiB、5000 条 |

API Key 由 Harness 凭据服务保存，设置页只显示是否已配置。
